# CoreConnect 
The Employee Profiling System is a web-based application designed to streamline employee management within our organization.

It serves as an internal employee directory, similar to LinkedIn, and allows HR, RMG (Resource Management Group), Managers, Candidates, and Admin users to efficiently manage and access employee information.

The primary goal is to enhance employee engagement, streamline HR processes, and provide valuable insights for decision-making.

# Prerequisites
- Operating System: Windows 10, macOS 10.10 (Yosemite) or later, or a recent distribution of Linux (such as Ubuntu 18.04 or later)
- Memory: At least 4 GB RAM
- Storage Space: At least 10 GB of free disk space
- Node.js version required ^18.13.0 || ^20.9.0
- Git version control system

## INSTALLING
To run this project, install it locally using npm
- Clone this repository
```bash
git clone https://github.com/NagoriMustakim/CoreConnect.git
```
- Navigate to project directory
```bash
cd frontend
```

- [Install Angular CLI Globally](https://angular.io/cli) or you can install via following command
```bash
npm install -g @angular/cli
```
- Next step is to install all it's dependencies
```bash
npm install
```
- Start angular server
```bash
ng serve -o
```

# Build
Build your application for production.
```bash
ng build
```
